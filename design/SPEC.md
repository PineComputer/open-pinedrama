# Studio re-theme: tokens, icons, components

This is the spec for the pro direction (https://claude.ai/artifact/8v2dRgRKL1Gpu7fZyWG1uR). Its source of truth is studio.css, screens.js and app.js in this folder. Colours, type, space and radii are reveric's tokens (themes.css, tokens.css; classic palette). Values not in those tokens are listed here.

## Theme
- `<html data-palette="classic" data-theme="light|dark">`. The Light/Dark/System setting resolves System from prefers-color-scheme. Dark is the default look.
- Fonts: system sans for UI, system mono for ids, codes, money and times. Courier Prime (or the mono stack) is used only for Fountain text.
- Our own layout sizes: `--rail 52px`, `--side 248px`, `--agent 360px`, `--insp 380px`, `--reel 232px`, `--top 52px`.

## Icons
Phosphor regular, 70 names (icons.js). Sizes: 16 default, 18 in IconButton and NavRail, 15 in Segmented, 14 in chevrons and steps, 24 in AgentBall.

## Shape and alignment
The rule and its grounds: [docs/studio/design-system.md](../docs/studio/design-system.md#shape-and-alignment). The values:

| Role | Radius | Elements |
|---|---|---|
| Press or read | `--radius-pill` | Button, IconButton, StatusChip, chips, Segmented, badges and counts, tags (a code or time over a picture or a clip), progress, meter and step tracks, Toast |
| Surface | `--radius-2xl` | Panel, Dialog, StopCard, menus and popovers, a floating inspector, the agent panel's cards that stand alone on the ground |
| Card of work | `--radius-large` | DramaCard, AssetCard, an EpisodeCard's cover, a CanvasNode's card, players and big pictures in an inspector |
| Control or row | `--radius-medium` | inputs, textareas, selects and the search field, drop zones, the agent's composer, inline notices (a quoted ask, a sent card), rows with a hover or selected fill (tree, nav items, list rows, review reel items, menu items, radio choices such as the presets), Finding, code and prompt blocks, thumbnails from 40 px, the brand mark |
| Mark | `--radius-small` | thumbnails under 40 px, timeline clips and tracks, keyboard keys |
| Circle | `50%` | faces, status dots |
| Edge | `0` | the rail, the sidebar, the top bar, a docked inspector or agent panel, a table's rows, a strip across a surface's full width |

- Concentric: an element within 18 px of a `--radius-2xl` surface's corner takes 18 minus its inset, rounded down to a token: a 6 px inset takes `--radius-large` (12), an 8 or 10 px inset `--radius-medium` (8), a 12 px inset `--radius-small` (6); a card of work's picture inset by p takes `--radius-large` minus p the same way.
- No bordered box inside a surface: group by spacing, an `h3`/`h4` or a 1 px `--border-subtle` divider.
- The page gutter is `--space-2xl` (16 px) left and right for everything in `.scrollmain`: the bar, the page title, panels, tables, banners and grids. A surface's padding is `--space-3xl` (20 px) across and `--space-2xl` (16 px) down; the gap between blocks is `--space-2xl`.
- Spacing on the 4-point grid (`--space-xxs`, `-sm`, `-lg`, `-2xl`, `-3xl`, `-4xl`, `-6xl`); `--space-xs`, `-md`, `-xl` (6, 10, 14) only inside a control's own box.

## Labels (ship as written)
Accept, Send back, Send review, Next review, Pause production, Pausing…, Paused, Resume, Keep working, Stop analyzing, Accept v2, Send v2 back, Upload script, Start, Accept cut, Following the agent / Follow the agent, Episode script, Lineage, Script / Bible / Assets / Episodes / Delivery, Characters / Locations / Props, Out of date.

Names of things (IA §10): Take / 视频版本 (t01, t02…), never 镜头 (a shot) or 片段 (a segment); Cut / 剪辑成片 (v1, v2…), an episode's versioned film; Delivery / 交付, the drama's accepted cuts; Locations, never Scenes, which stay the screenplay's scenes (场戏).

"Studio" names the app only. Graph, World, Story and Cast / World as navigation are retired: the bible lives in Bible, drama-cli's name for it, and Lineage is a view of an item, not a page (IA §3, §10, §16).
